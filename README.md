# 다세대(빌라) AI 시세 모델 — 스카이키 과제

서울 **강남구·관악구·강서구 화곡동**의 다세대주택에 지번·층·호를 넣으면 매매 시세, 하한~상한, 신뢰도, 산출 근거 한 줄을 내는 모델입니다.
연립주택은 제외했습니다(근거: `결정기록.md` 1번).

## 1. 설치와 실행

```bash
pip install -r requirements.txt
python predict.py --input input.csv --output output.csv
```

- 산출 기준일은 과제 안내일 **2026-10-06**이 기본값입니다. 바꾸려면 `--base-date 2026-10-06`처럼 넣습니다.
- 실행 시간: 예시 21건 **약 25초** (CPU, 개발 PC 기준). 미리 수집하지 않은 지번은 1건당 약 1.6초가 더 걸립니다.
- 실행할 때마다 모델 3개를 새로 학습합니다(약 10초). 설정·난수가 고정돼 있어 매번 같은 결과가 나옵니다.
- 학습 데이터는 학습용 8,793건 + 시험용 2,181건 = **10,974건**입니다. 시험용으로 성능을 잰 뒤(7번) 모두 합쳐 다시 학습했습니다. 시험용 중 학습용과 같은 이상치 규칙에 걸리는 19건은 뺐습니다.
- 시험용 평가를 다시 재현하려면 `--train-only`를 붙입니다(학습용 8,793건만으로 학습).
- 예시: `sample/input_sample.csv` → `sample/output_sample.csv`

## 2. 입력·출력 (과제 03번 규격)

| 입력 칸 | 예시 | 비고 |
|---|---|---|
| id | 1 | |
| sigungu | 서울특별시 관악구 | |
| dong | 봉천동 | 법정동 |
| jibun | 123-45 | 산 지번은 미지원 |
| floor | 3 | 지하는 `-1`, `B1`, `지하1` 모두 가능 |
| ho | 301 | 없어도 됨. `301호`, `B01`, `지하B01`처럼 써도 공시가격 목록 표기에 맞춰 찾음 |
| area_m2 | 42.5 | 비어 있으면 공시가격 목록에서 찾고, 찾은 출처를 basis에 적음 |

| 출력 칸 | 뜻 |
|---|---|
| price_est | 추정 시세(원, 만원 단위 반올림) |
| price_low, price_high | 실제 거래가가 이 범위에 들 확률 약 80% |
| confidence | 0~1. **실제 거래가가 추정가 ±10% 안에 들 확률** (예: 0.5 = 이런 물건은 절반이 ±10% 안) |
| basis | 산출 근거 한 줄 (반경 500m·최근 12개월 비슷한 면적(±20%) 거래로 만든 기준가 대비 %, 공시가격의 몇 배, 건물 특징, 신뢰도와 이유) |
| status | `ok` 또는 `fail`. fail이면 사유를 basis에 `산출 불가: …`로 적음 |

fail이 되는 경우: 권역 밖 주소, 지번·층을 읽지 못함, 지번 좌표를 찾지 못함, 미리 수집하지 않은 지번인데 API 키가 없음.

## 3. API 키 (미리 수집하지 않은 지번을 조회할 때만 필요)

수집해 둔 지번(5,317개)은 키 없이 산출됩니다. 그 밖의 지번은 실행 중에 좌표·건축물대장·공시가격을 조회하므로 아래 키가 필요합니다.
환경변수로 넣거나, 프로젝트 폴더에 `.env` 파일을 만들어 넣습니다(`.env`는 제출물에 포함하지 않음).

```
DATA_GO_KR_KEY=공공데이터포털 인증키
VWORLD_KEY=VWorld 인증키
```

| 키 | 발급 방법 | 쓰는 곳 |
|---|---|---|
| `DATA_GO_KR_KEY` | [공공데이터포털](https://www.data.go.kr) 로그인 → 「국토교통부_건축HUB_건축물대장정보 서비스」(15134735) 활용신청 → 마이페이지의 일반 인증키 (실거래를 다시 수집하려면 「국토교통부_연립다세대 매매 실거래가 자료」(15126467)도 신청) | 건축물대장 표제부, (재수집 시) 실거래 |
| `VWORLD_KEY` | [VWorld](https://www.vworld.kr) 회원가입 → 오픈API 인증키 발급. **서비스URL을 `http://localhost`로 등록** (코드가 이 주소로 호출하며, 다르면 `INCORRECT_KEY` 오류) | 지번 → 좌표(지오코더), 공동주택 공시가격 |
| `SEOUL_KEY` | [서울 열린데이터광장](https://data.seoul.go.kr) 인증키 | 지하철역 위치를 다시 수집할 때만 (predict.py는 필요 없음) |

## 7. 모델 요약

- **추정:** CatBoost (log 거래가를 학습해 원 단위로 되돌림). 입력은 전용면적, 층, 건물 나이, 역 거리, 반경 500m 노선 수, 공시가격(㎡당), 세대수, 승강기, 세대당 주차, 시점, 반경 500m·최근 12개월 주변 거래 ㎡당 중앙값, 동, 구조 (변수 선정 근거: `결정기록.md` 4·6번)
- **신뢰도:** 주변 거래 수, CatBoost·XGBoost·LightGBM 예측 차이, 권역으로 계산한 로지스틱 회귀
- **구간:** 신뢰도 등급(낮음·보통·높음)마다 최근 12개월 거래의 실제÷추정 하위·상위 10% 지점
- **자체 검증:** 학습용 지번 단위 5조각 교차검증 MAPE 14.40%. 시험용(학습에 안 쓴 지번 20%, 2,200건) MAPE 14.55%, 최근 12개월 15.57%, ±10% 안 50.6% (`reports/test_report.html`). 이 숫자는 학습용만으로 학습한 모델의 결과이고, 제출본은 그 뒤 시험용까지 합쳐 다시 학습했습니다
