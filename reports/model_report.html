1. 비교 방법

항목 내용
데이터 학습용 8,793건만 사용 (시험용 2,200건은 9단계에서 한 번만)
검증 방식 지번 단위 5조각 교차검증: 학습용을 5조각으로 나눠, 4조각으로 학습하고 1조각으로 검증하기를 5번 반복. 같은 건물(지번)은 한 조각에만 들어감 → 모델이 건물 가격을 외워서 맞히는 것을 막음
타깃 모든 모델이 log(거래가)로 학습 → 예측을 원 단위로 되돌려 오차 계산
기준선 동별 ㎡당 중앙값 × 전용면적 (학습 조각으로 중앙값 계산, 학습 조각에 없는 동은 같은 구 중앙값). 학습 없는 가장 단순한 방법 = 넘어야 할 최소 점수
회귀 계열 OLS(일반 선형회귀, 스케일 없음), ElasticNet(릿지+라쏘 규제, 스케일 켬, 규제 세기·비율은 학습 조각 안에서 자동 선택) — 입력 31칸
트리 계열 LightGBM, XGBoost, CatBoost (기본 설정) — 입력 16칸 (동·구조 라벨 인코딩)
딥러닝 MLP(scikit-learn 기본 신경망, 은닉층 100개 1층, 조기 종료) — 입력 31칸, 표준화 켬 (신경망은 스케일링 필수)

2. 평가 지표

지표 계산 답하는 질문 한계
MAPE (평균 오차율) 모든 거래의 |예측 − 실제| ÷ 실제 를 평균 평균적으로 몇 % 틀리나 크게 틀린 몇 건에 끌려 올라갈 수 있음
중앙값 오차율 같은 오차율의 중앙값 보통의 물건은 몇 % 틀리나 크게 틀린 건이 얼마나 심한지는 안 보임
±10% 안 비율 오차율 10% 이하인 거래 비율 실무에서 '맞혔다'고 볼 만한 비율 10%라는 선은 관례적 기준
왜 평균 오차율(MAPE)을 주 지표로 썼나
  • 과제가 오차율로 평가함: 블라인드 검증에서 "실제 실거래가 대비 오차율"과 "하우스머치 AI 시세 대비 오차율"을 봄 (과제 07번)
  • 가격대가 달라도 공정함: 거래가가 0.2억 ~ 30억으로 폭이 넓음. 원 단위 오차(MAE, RMSE)는 1억 틀리는 게 2억 집이든 10억 집이든 같게 취급해 비싼 강남 거래가 점수를 좌우함. 오차율은 2억 집 2천만원 오차와 10억 집 1억 오차를 같은 10%로 봄
  • 설명하기 쉬움: "평균 12% 틀린다"는 비전공자도 바로 이해함 (과제 평가 '문서와 전달력')
  • 타깃 log와 맞음: log로 학습하면 모델이 원래 % 오차를 줄이도록 배움
MAPE 하나만 보면 크게 틀린 몇 건에 끌릴 수 있어서 중앙값 오차율과 ±10% 안 비율을 함께 봄.

회귀 계열과 트리 계열의 평가 지표는 같음: 지표는 모델 종류가 아니라 문제 종류로 정해짐. 여기서는 모두 "가격(숫자)을 맞히는 문제(회귀 문제)"라서 같은 지표로 비교함. 트리 모델도 여기서는 숫자를 내는 '트리 기반 회귀 모델'임. 정확도·F1 같은 지표는 "어느 범주인가"를 맞히는 분류 문제용.

계수를 읽을 때 주의
  • 계수는 다른 칸을 모두 고정했을 때의 효과임. 공시가격(pub_ppm, 계수 0.80)이 이미 건물 나이·층 같은 개별요인을 반영하고 있어서 (건물 나이 ↔ 공시가격 상관 −0.71), 건물 나이 1 늘면 거래가 +0.60% · 층 1 늘면 거래가 -0.70%처럼 EDA에서 본 방향과 반대로 나올 수 있음 → "공시가격이 같다면" 붙는 보정으로 읽어야 함. basis 문장에 그대로 쓰면 오해 소지 있음
  • pub_ppm_missing의 큰 +계수: 공시가격이 없던 행(주로 공시 뒤 신축)을 동 중앙값(낮은 값)으로 채웠기 때문에, 표시 칸이 그 차이를 보정하는 것
  • hhld_cnt_missing과 parking_per_hh_missing은 완전히 같은 행이라 두 계수가 효과를 반씩 나눠 가짐 → 둘을 합쳐서 읽어야 함

CatBoost 변수 중요도

중요도는 "그 칸으로 나눴을 때 오차가 얼마나 줄었나"의 합(gain)을 비율로 나타낸 것. 방향(+/−)은 알려 주지 않음.

7. OLS와 ElasticNet의 차이

OLS ElasticNet
무엇을 줄이나 예측 오차만 최소화 예측 오차 + 계수 크기에 대한 벌점
벌점 없음 릿지(L2: 계수를 고르게 작게) + 라쏘(L1: 쓸모없는 계수를 0으로)를 섞음
겹치는 변수 계수가 불안정해질 수 있음 (VIF 높은 공시가격·주변 시세) 벌점 덕분에 계수가 안정됨
스케일링 불필요 (예측 같음) 필요 (벌점이 계수 크기에 걸리므로 단위가 다르면 불공평)
계수 해석 그대로 % 효과로 읽음 벌점 때문에 0 쪽으로 줄어 있어 효과가 작게 나옴
R로 치면 lm() glmnet (alpha = 라쏘 비율)

둘 다 "직선 관계"를 가정하는 같은 회귀 모델이고, 차이는 벌점(규제) 유무뿐. 데이터가 많고 변수가 적으면 두 결과가 비슷하게 나옴.
