5. 탐색 과정

점 = 끝까지 간 시도의 MAPE, 선 = 그때까지의 최고 기록. 선이 일찍 평평해지면 더 시도해도 나아질 여지가 적다는 뜻.

6. 학습 곡선 — 과소·과대적합 확인

검은 선 = 학습 조각(모델이 본 데이터) MAPE, 빨간 선 = 검증 조각(처음 보는 데이터) MAPE. 두 선이 모두 높으면 과소적합(덜 배움), 학습 선은 계속 내려가는데 검증 선이 바닥을 찍고 다시 오르면 과대적합(외움). 두 선 사이 간격은 있어도 정상 — 판단 기준은 검증 선이 다시 오르는지. 배경은 검증 MAPE가 가장 낮은 지점 기준, 점선 = 튜닝값 (MLP는 회색 구간과 점). 가로축은 튜닝값의 2배까지 (ElasticNet은 학습 시간 개념이 없어 규제 세기 0.00001~1의 검증 곡선). 검증 조각이 일반적인 그림의 'Test loss' 자리 — 시험용 2,200건은 쓰지 않음.

튜닝값 → 끝 변화: 튜닝값에서 가장 복잡한 끝(트리·MLP = 튜닝값의 2배, ElasticNet = 규제 가장 약함)까지 검증 MAPE가 몇 %p 변했나. 양수 = 더 복잡하게 하면 나빠짐(과대적합 시작), 음수 = 더 좋아짐(아직 덜 배움). MLP는 —: 조기 종료가 고른 골짜기 값과 5조각 평균 곡선은 기준이 달라 빼지 않음.

MLP는 튜닝값이 고정된 숫자가 아니라 조기 종료: 학습 조각의 10%를 연습용으로 떼고, 연습용 점수가 10번 연속 안 오르면 멈춘 뒤 가장 좋았던 epoch으로 되돌아감 → 조각마다 고른 epoch이 달라 회색 구간(48~76 등)으로 표시. 곡선은 튜닝 모델과 같은 조건으로 학습하되 멈추지 않고 끝까지 간 경로. 가는 선 = 조각별 검증 곡선, 점 = 각 조각이 고른 지점. 성적이 epoch마다 들쭉날쭉해서 조기 종료는 각 조각 곡선의 골짜기를 고름 → 점들을 모은 튜닝 결과가 5조각 평균 곡선(굵은 빨간 선)보다 낮게 나옴. 모든 모델에서 표의 튜닝값 검증 MAPE = 튜닝 결과 (실행 중 확인). MLP의 학습 MAPE에는 연습용 10%도 포함.

7. 주의

  • 튜닝과 평가에 같은 5조각을 썼기 때문에 튜닝 후 점수는 약간 낙관적임 → 최종 성능은 9단계에서 시험용 2,200건으로 한 번만 측정
  • 개선 폭이 작으면 튜닝 효과보다 조각 간 흔들림(5단계 표준편차 0.7~2.4%p) 안의 차이일 수 있음
