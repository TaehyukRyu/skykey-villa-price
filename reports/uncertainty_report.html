1. 방법

항목 내용
confidence 뜻 (사용자 결정) 실제가가 추정가 ±10% 안에 들 확률. 지금까지 모든 표의 '±10% 안 비율'과 같은 자 → 0.6이면 '이런 물건은 10건 중 6건이 ±10% 안'
confidence 계산 (사용자 결정) 로지스틱 회귀 = R의 glm(적중 ~ 재료, family=binomial). 적중 = 오차율 10% 이하면 1, 아니면 0
재료 (사용자 결정) ① log(1+주변 거래 수): 반경 500m·최근 12개월 다른 지번 거래 건수. 적을 땐 크게, 많아지면 평평한 모양이라 log ② 세 모델 엇갈림(%): 그대로 — 크게 엇갈릴 때만 급하게 나빠지는 모양 ③ 권역 (기준 강서구 = 학습용 최다, AI가 정함). 공시가격 찾은 수준은 적중률 차이가 거의 없어(호까지 50% vs 층까지 49%) 제외
구간 (사용자 결정) 오차 분포 + 등급별: 등급마다 과거 오차(실제 ÷ 추정)의 하위 10%·상위 10% 지점 → 가운데 80%가 들어가는 범위. 믿을 만한 물건은 좁게, 불확실한 물건은 넓게
등급 (AI가 정한 세부 규칙) confidence 3등분 → 낮음·보통·높음 (등급마다 약 1,200건이라 구간 계산이 안정적)
규칙 기준 (사용자 결정) 최근 12개월(2025-10-01 이후) 거래 3,623건. 처음엔 3년 전체로 정했더니 최근 거래에서 구간 적중 76.6%·confidence 과신(평균 0.51 vs 실제 45.7%). 최근 거래는 치우침 없이(실제÷추정 중앙값 1.00) 위쪽으로 더 크게 흩어짐(상위 10% 지점 1.26~1.28배 vs 그 이전 1.20~1.24배) → 블라인드 검증 물건과 같은 시기로 맞춤 (연립 제외 때와 같은 원칙)
채점 방법 이중 교차검증: 5조각 중 4조각의 최근 거래로 confidence 계수·등급 경계·구간 폭을 정하고 나머지 1조각에서 채점, 5번 반복. 모든 표의 숫자는 이 방식 (규칙을 정할 때 본 거래는 채점에 안 씀)
predict.py용 규칙 학습용 최근 12개월 전체로 다시 정해 reports/uncertainty_params.json에 저장. 파일만으로 계산한 값이 메모리 값과 같은지 실행 중 확인

7. 주의

  • 규칙을 최근 12개월 거래로만 정해 3년 전체보다 계수의 흔들림(표준오차)이 큼 — 5번 표의 표준오차 참고
  • 교차검증 예측은 학습용 4/5로 학습한 모델의 값 → predict.py의 최종 모델(학습 데이터가 더 많음)은 오차가 조금 작을 수 있어 구간이 약간 넓게(보수적으로) 잡힐 수 있음 (추정). 9단계 시험용으로 확인
  • 엇갈림을 쓰므로 predict.py는 CatBoost 외에 XGBoost·LightGBM도 학습·실행해야 함 (추정값은 CatBoost만 사용)
  • 면적을 입력 대신 건축물대장에서 찾았거나 못 찾은 경우처럼 학습 데이터에 없는 상황은 이 규칙이 반영하지 못함 → predict.py에서 따로 처리 필요
